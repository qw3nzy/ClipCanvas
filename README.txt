ClipCanvas 2.0.0 — нарезка полного видео и рекламная интеграция для Windows 10/11 x64

Полное видео → части → рекламный ролик внутри каждой части → проверка → отдельные MP4.
При рекламной вставке основное изображение останавливается, его звук выключается; после рекламы исходное видео продолжается с того же места. Субтитры учитывают добавленное время.

ЗАПУСК
1. Распакуйте весь архив в доступную для записи папку.
2. Дважды нажмите «Запустить.cmd». Откроется http://127.0.0.1:8787.
3. При первом запуске устанавливаются отсутствующие зависимости в .runtime. Подходящий Python 3.12/3.13 x64 используется повторно; иначе загружается переносимый Python с проверкой SHA256.
4. Для завершения программы запустите «Остановить.cmd» из этой же папки.
Если до обновления оставался запущен ClipCanvas 1.x, сначала остановите старый экземпляр. Два экземпляра из одной папки не запускаются одновременно.

ВИДЕО
Загрузите файл или откройте «Видео по ссылке»: проверьте публичный URL, выберите доступное качество и начните загрузку. Скачивает компьютер с движком. Закрытые страницы, DRM и источники, требующие авторизации, не поддерживаются автоматически; cookies браузеров программа не импортирует.
Импорт по ссылке адаптирован из Yoinks (https://github.com/pablostanley/yoinks) под Python/yt-dlp. Deno используется для JavaScript-задач загрузчика. Поддержка зависит от конкретного сайта и его текущих ограничений; поддержка всех сайтов не обещается. Лицензии: THIRD_PARTY_NOTICES.md.
Выберите нужную звуковую дорожку: одна дорожка применяется к распознаванию и экспорту.

СУБТИТРЫ
Сначала проверьте встроенные текстовые дорожки и нажмите «Извлечь дорожку». Можно импортировать текст и таймкоды из SRT, ASS или VTT.
Если текстовых субтитров нет, нажмите «Распознать речь». tiny — быстрее, base — обычная, small — точнее. Модель при первом использовании скачивается; затем распознавание выполняется локально на процессоре. Проверьте текст вручную.
Стили: «Чистый» — обычный текст с обводкой; «Акцент на слове» — выделение текущего слова при наличии таймкодов слов; «Кино» — спокойное оформление. Настройте размер, цвет и положение, затем проверьте образец.
Встроенные графические субтитры DVD/PGS не распознаются через OCR. Текст, уже вшитый в изображение, нельзя извлечь как отдельную текстовую дорожку.

МОНТАЖ И НАРЕЗКА
Выберите холст 9:16, 16:9, 1:1 или своё чётное разрешение от 240 до 3840 px.
Выберите слой и перетащите его или измените размер за углы. «Вписать» сохраняет пропорции, «Заполнить» обрезает края, «Растянуть» меняет пропорции.
Размытый фон можно заменить сплошным цветом. Статичный баннер — отдельный необязательный слой PNG/JPG/WebP/GIF; GIF используется как неподвижное изображение.
Режимы нарезки: «По длительности», «Равные части» и «Интервалы». В таблице проверьте границы и итоговую длительность с рекламой. Режим по длительности относится к исходному материалу: рекламная вставка увеличивает длительность готовой части.
Нарезка делит материал по времени; автоматическое определение интересных сюжетов или смысловых эпизодов не реализовано.

РЕКЛАМНАЯ ИНТЕГРАЦИЯ
Загрузите отдельный рекламный видеоролик со звуком и выберите профиль:
• FloatUP: начало на 20-й секунде части, повторение через 60 секунд; настройки можно проверить перед экспортом.
• MEDIA BUBA: одна вставка в середине исходной части, рекламный слой по центру. Размер подбирается под пропорции рекламного файла и не менее 25% площади кадра до хромакея; невозможность вписать такой размер показывается предупреждением. Скорость не выше 1,2×. Для соответствующих материалов есть хромакей.
• «Свои настройки»: положение, время, повторение и скорость задаются вручную.
Повторение отсчитывается по итоговой шкале времени части. Реклама должна быть короче интервала повторения.
Если реклама начинается позднее конца короткой части, измените время или профиль. Проверьте каждую часть в списке.
Профили помогают настроить монтаж. Они не подтверждают принятие ролика рекламодателем: сверяйте результат с актуальными правилами и своим заданием.
MEDIA BUBA: https://t.me/bubavpn_media . В публичном канале MEDIA BUBA PRO представлен как инструмент автоматических баннеров/субтитров и связан с @BubasikHelp_bot. Ссылка на бот открывается вручную; ClipCanvas не отправляет туда видео и не использует неизвестный API.
«Чистый экспорт без рекламного ролика» создаёт версию без видеовставок, сохраняя основной монтаж и субтитры.

ПРОВЕРКА И ЭКСПОРТ
Сначала создайте короткий образец. Проверьте звук, переход в рекламу и обратно, её размер, хромакей, таймкоды и субтитры. Браузерный предпросмотр может отличаться от итогового FFmpeg, особенно при хромакее и оформлении текста.
Экспорт создаёт отдельные MP4 (H.264/AAC), SRT при включённых субтитрах и сведения о выполнении. ZIP выключен по умолчанию: включайте его, если нужен один архив.
Кодирование: «Авто» использует NVIDIA NVENC, если пробное кодирование прошло успешно; иначе — процессор. Можно выбрать «NVIDIA · видеокарта» или «Процессор» вручную. При сбое NVIDIA автоматический режим пересобирает текущую часть на процессоре. Размытие, слои и субтитры обрабатываются на CPU, поэтому выигрыш зависит от монтажа. Размер MP4 при одинаковом выбранном качестве может отличаться между CPU и NVIDIA.
История задач сохраняется на компьютере с движком. После возвращения в браузер можно проверить состояние, скачать результаты или повторить задачу после исправления её причины.
Для TikTok подготовлены файлы; автоматическая публикация не подключена. При публикации ролика с рекламой включите Content disclosure / «Раскрытие коммерческого контента» и проверьте права на музыку.

ПРОЕКТЫ, ДАННЫЕ И ПРОИЗВОДИТЕЛЬНОСТЬ
Проект сохраняет настройки и ссылки на загруженные материалы; JSON проекта не содержит само видео. Для проекта нужны соответствующие файлы в data/uploads. Автосохранение действует в текущем проекте; перед переносом на другой компьютер сохраните JSON и исходные материалы отдельно.
Видео/реклама/баннеры: data/uploads. Результаты: data/jobs. Проекты: data/projects. Модели: data/models.
Программа не отправляет видео в облако для монтажа или распознавания. Интернет нужен для установки, загрузки модели и импорта видео по URL.
Для фильма нужны свободное место под исходник, промежуточные фрагменты и результат; ZIP дополнительно копирует результаты. Перед длинным экспортом проверьте свободное место на диске.
Для первых проверок используйте короткий образец, обычное качество, 30 FPS и tiny/base. Полный рендер большого видео занимает время в зависимости от процессора, видеокарты, эффектов и разрешения. Для NVIDIA нужны совместимая видеокарта и рабочий драйвер; на компьютерах без NVENC автоматический режим использует CPU.
«Остановить» в редакторе отменяет задачу. Полное завершение движка прерывает обработку; после повторного запуска проверьте историю и при необходимости повторите экспорт.

НОУТБУК → ПК ЧЕРЕЗ VPN
По умолчанию сервер доступен только на 127.0.0.1. Подготовлен отдельный запуск на конкретном VPN-IP ПК с токеном; обработка выполняется на ПК, браузер открывается на НОУТБУКЕ. Сеть, VPN и Windows Firewall автоматически не меняются.
Пошаговая инструкция: docs/remote-access.md. Подключение двух реальных устройств ещё не проверено.

ФОРМАТЫ И ОГРАНИЧЕНИЯ
Вход: форматы и кодеки поставляемого FFmpeg, включая MP4/MOV/MKV/AVI/WebM. Неподдерживаемый браузером файл преобразуется для предпросмотра; экспорт использует исходник.
Повреждённые файлы, DRM и неизвестные кодеки могут не открываться. Выход — SDR; специальный HDR→SDR tone mapping не реализован.
Предпросмотр и итоговый рендер могут немного различаться по сглаживанию, переносу текста и размытию. Короткий образец помогает проверить фактический результат.
