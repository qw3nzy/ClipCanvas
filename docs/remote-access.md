# НОУТБУК → ПК: обработка видео через частный VPN

Это подготовленный режим работы ClipCanvas. Подключение двух реальных устройств пока не проверено. Программа сама не настраивает VPN, Windows Firewall, переадресацию портов или автозапуск.

**ПК** — компьютер, где находится папка ClipCanvas и работает Python/FFmpeg. **НОУТБУК** — устройство, где открывается браузер. Видео, проекты, модели и результаты хранятся на ПК; рендер и распознавание выполняются там же.

## Обычный локальный запуск

**ПК:** двойной щелчок по `Запустить.cmd`. По умолчанию доступен только `http://127.0.0.1:8787`. Адрес `127.0.0.1` на НОУТБУКЕ обозначает сам НОУТБУК, поэтому для удалённого режима используется VPN-адрес ПК.

## Подготовка и запуск на ПК

1. **ПК и НОУТБУК:** подключите оба устройства к частному VPN, который позволяет устройствам обращаться друг к другу. Одинаковый VPN-провайдер или общий выходной IP сами по себе этого не гарантируют.
2. **ПК:** остановите локальный движок через `Остановить.cmd`. Одна папка ClipCanvas обслуживает один экземпляр движка.
3. **ПК:** узнайте адрес VPN-интерфейса ПК в вашем VPN-клиенте. Здесь он обозначен `<VPN_IP_ПК>`; замените обозначение на фактический адрес. Не используйте адрес НОУТБУКА.
4. **ПК:** откройте PowerShell в папке ClipCanvas и запустите:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Start.ps1 -NoBrowser -BindAddress '<VPN_IP_ПК>' -Port 8787
```

Скрипт принимает конкретный IP, назначенный этому ПК. `0.0.0.0` и `::` запрещены. Он выводит адрес движка и путь к закрытому файлу токена, без самого секрета. При недоступном VPN-интерфейсе запуск останавливается.

5. **ПК:** откройте файл токена под той же учётной записью Windows:

```powershell
notepad.exe "$env:LOCALAPPDATA\ClipCanvas\access-token.txt"
```

Скопируйте токен вручную для входа с НОУТБУКА. Не добавляйте его к ссылке и не публикуйте файл. Права NTFS ограничены текущим пользователем и SYSTEM. Токен общий для запусков ClipCanvas под этой учётной записью.

## Работа на НОУТБУКЕ

1. **НОУТБУК:** откройте `http://<VPN_IP_ПК>:8787` в браузере. Интерфейс и API должны открываться с одного адреса ПК; отдельная локальная копия сайта на НОУТБУКЕ не требуется.
2. **НОУТБУК:** в блоке подключения укажите тот же адрес и токен. Нажмите «Подключить». Токен передаётся в теле запроса, после входа браузер использует HttpOnly-сессию. Секрет не хранится в URL; поле токена очищается.
3. **НОУТБУК:** загрузите полное видео или используйте «Видео по ссылке». При загрузке файла он передаётся по VPN на ПК. При импорте по URL файл скачивает ПК.
4. **НОУТБУК:** выберите дорожку звука, субтитры, нарезку и рекламную интеграцию, проверьте короткий образец, запустите экспорт. Закрытие вкладки не выключает движок на ПК. После возвращения проверьте историю задач.
5. **НОУТБУК:** скачайте готовые MP4/SRT/ZIP на НОУТБУК или используйте файлы непосредственно на ПК.

**ПК:** останавливайте движок через `Остановить.cmd` из той же папки. Сначала отправляется запрос завершения конкретного экземпляра, затем при необходимости останавливаются проверенные процессы этого движка и его дочерние процессы обработки.

## Проверка при реальном подключении

Проверить предстоит запуск на адресе VPN, доступ с НОУТБУКА, отказ без токена, загрузку большого файла, обработку на ПК, повторный вход и скачивание результатов. Проверки локального запуска и остановки на одном компьютере не подтверждают работу этой цепочки между двумя устройствами.

Если страница не открылась, сначала проверьте состояние VPN и правильность IP/порта. Если сеть доступна, но Windows Firewall запрещает вход, отдельное правило можно подготовить для нужного VPN-интерфейса и устройств; ClipCanvas правил не создаёт. Не открывайте порт в интернет. HTTP-режим рассчитан на защищённый частный VPN; публичный доступ требует отдельной настройки HTTPS и разграничения доступа.

Для смены токена **ПК:** остановите движок, удалите только `%LOCALAPPDATA%\ClipCanvas\access-token.txt` и повторно запустите `Start.ps1`. Он создаст новый секрет. Старые сессии исчезают при перезапуске; на НОУТБУКЕ потребуется повторный вход.
