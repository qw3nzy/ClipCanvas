# Проверка ClipCanvas 2.0.0

Проверено 5 октября 2026 на текущем Windows-компьютере. Резервная копия исходного кода: `.backups/before-v2-20261005-003251`. Исходные видео и ранее готовые результаты сохранены.

## Выполненные проверки

- 21 модульная/API-проверка: рекламная шкала времени, перенос субтитров, текущий акцент слова, импорт текста, очередь/отмена/продолжение, сохранение ссылок проекта, авторизация и проверка публичных URL.
- Реальный FFmpeg: 6 секунд исходника + две вставки по секунде → 192 кадра при 24 FPS. Переходы проверены по цвету кадров с точностью до одного кадра. Разные частоты звука подтвердили выбранную дорожку, отдельный звук рекламы и возобновление исходника. Проверены SRT, MP4, необязательный ZIP и сохранённый проект.
- MEDIA BUBA: середина клипа, скорость 1,2×, хромакей с видимым замершим исходником под рекламой. Визуально проверены кириллические стили «Акцент на слове» и «Кино».
- Настоящий ASR без интернета: 15 секунд русской речи, локальная tiny, 3 фразы и 10 слов с валидными таймкодами. Первый запрос — 3,61 секунды; повтор вернул идентичный кэш. Это проверка работоспособности, а не оценка точности на любых видео.
- Браузер: загрузка, выбор звука и proxy, извлечение встроенных субтитров, реклама, интервалы, сохранение, перезагрузка, редактирование восстановленного проекта и настоящий экспорт. Проверены ширины 1600, 736 и 320 px, ошибок JavaScript и горизонтального переполнения не обнаружено.
- Yoinks: настоящий импорт публичного ролика W3C через API; через интерфейс — проверка ссылки, выбор качества и импорт CC0-ролика MDN. Повторный запрос к W3C получил HTTP 403 от сайта: это ограничение источника, поддержка любого URL не гарантируется.
- Запуск/остановка Windows PowerShell 5.1: повторный запуск, конфликт порта, остановка дочерних процессов, защита от чужого PID, проверка зависимостей и права доступа к токену.
- Старые материалы: у полного видео определены 4 аудио- и 4 текстовые субтитровые дорожки. Из выбранной русской дорожки извлечены 336 реплик; пробный отрезок 60–68 секунд экспортирован в 540×960 с выбранным звуком и субтитрами.

## Воспроизведение

### Дополнительная проверка NVIDIA NVENC

Проверено на RTX 4060 (драйвер 616.92) и Ryzen 7 5700X:

- 27 модульных/API-проверок, включая отсутствие GPU, сбой драйвера, повтор всей текущей части на CPU и отмену без повторного рендера.
- Отдельные реальные экспорты CPU и NVIDIA: 192 кадра при 24 FPS, рекламные переходы, выбранный звук, SRT и ZIP. Проверены хромакей, скорость рекламы 1,2× и кириллические стили субтитров.
- Браузер: определение GPU, сохранение/восстановление выбранного кодировщика и настоящий экспорт NVIDIA.
- Замер полного экспорта синтетического ролика: исходник 1280×720, 8 секунд; выход 1080×1920, 30 FPS, размытый фон и субтитры. Медиана двух запусков с чередованием порядка CPU/NVIDIA:

| Качество | CPU | NVIDIA | Сокращение времени |
| --- | ---: | ---: | ---: |
| Обычное | 2,24 с | 2,14 с | около 4% |
| Высокое | 3,27 с | 2,43 с | около 26% |

Замер относится к этому тесту, а не ко всем видео. Профили кодировщиков отличаются: MP4 NVIDIA в этом тесте были больше. Размытие, слои и текст остаются на CPU; их обработка использует до восьми потоков вместо двух.

Для повторения используйте `python -B tests/integration_smoke.py --encoder nvidia --keep-server`, затем `python -B tests/benchmark_render.py <путь-к-result.json>`. Сценарий печатает адрес и PID отдельного QA-сервера; после проверки завершите именно этот тестовый процесс. Замеры сохраняются рядом с его `result.json` в `benchmark-result.json`.

Используйте Python приложения с зависимостями из `.runtime/deps`:

```text
python -B -m unittest discover -s tests -p "test_*.py" -v
python -B tests/integration_smoke.py
python -B tests/network_import_smoke.py
python -B tests/launcher_smoke.py
```

`tests/test_asr_smoke.py` использует текущий локальный исходник и установленную tiny. Браузерные сценарии `tests/ui_smoke.cjs` и `tests/ui_link_smoke.cjs` требуют Playwright, Chromium и адрес изолированного QA-сервера. Снимки, результаты и журналы находятся в `.runtime/qa`.

## Оставшиеся ограничения

Соединение НОУТБУК → ПК через реальный частный VPN не проверено; инструкция находится в `remote-access.md`. OCR графических/вшитых субтитров и специальное HDR→SDR-преобразование не реализованы. Поиск сцен с ИИ требует редакторского просмотра и оценивает только выборочные кадры. Аппаратное кодирование проверено только для NVIDIA NVENC; AMD и Intel используют CPU. Оформление текста и хромакей окончательно проверяйте по пробному MP4. Реальные рекламные файлы пользователь ещё не загрузил; профили сверяйте с актуальным заданием рекламодателя.


## Студия 2.1 и локальная модель

Проверено 5 октября 2026 на RTX 4060 8 ГБ, Ryzen 7 5700X, 16 ГБ RAM:

- 38 модульных проверок: существующий монтаж, безопасные границы ИИ, включение
  завязки и развязки, перекрывающиеся окна, удаление дубликатов, настоящие метки
  слов, шаблоны без пользовательских материалов, отсутствие перезаписи субтитров
  при обновлении прогресса.
- Настоящий FFmpeg: обзор исходника, JPEG-кадры, звуковая волна и повтор из кэша;
  проверка готового MP4 на декодирование, чёрный экран и тишину. Повторно пройден
  экспорт NVIDIA с рекламой, выбранным звуком и SRT.
- Ollama 0.35.1 + qwen3.5:4b, 3 324 173 934 байта весов. В журнале подтверждено
  размещение всех 33 слоёв модели и визуального кодировщика на CUDA.
- Настоящий запрос с шестью кадрами и контрольным диалогом: выбрана шутка целиком,
  включая ответ. Обработка тестового окна заняла 6,16 с; это не оценка скорости
  полнометражного фильма. Исправление «Привет как дела» → «Привет, как дела?»
  сохранило исходное время. Отмена запроса к модели — 0,27 с; повтор завершился.
- Минутный участок локального материала без готовых субтитров: Whisper Small
  автоматически распознал английскую речь, Qwen выбрал фрагмент, создан MP4
  720×1280 с подсветкой слов. Первый анализ с загрузкой модели речи — 46,66 с,
  экспортирован клип 16,06 с. Полный фильм целиком в этом прогоне не анализировался.
- Браузер: I/O, перетаскивание границы, точные тайм-коды, отмена/возврат, масштаб,
  применение и сохранение шаблона, просмотр исправлений, поиск реплик, проверка
  монтажа и восстановление обзора после перезагрузки. Ширины 1536, 736 и 320 px
  без горизонтального переполнения; ошибок JavaScript нет.

Воспроизведение после `tests/integration_smoke.py --keep-server`:

```text
python -B tests/studio_smoke.py <путь-к-result.json> --ai
node tests/ui_studio_smoke.cjs <путь-к-result.json>
```

Без `--ai` серверный сценарий не обращается к модели. Для ИИ нужна установка через
`Setup-AI.cmd`; браузер использует `CLIPCANVAS_PLAYWRIGHT` и `CLIPCANVAS_CHROMIUM`.
Сценарии работают с отдельной папкой QA. Локальный образец пользовательского видео
для дополнительной проверки не включён в репозиторий и не отправлялся в облако
анализа. Доказательства текущего прогона: `.runtime/qa/integration-4k267y39/`.
