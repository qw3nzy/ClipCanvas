| Качество | CPU | NVIDIA | Сокращение времени |

Оформление текста и хромакей окончательно проверяйте по пробному MP4. Реальные рекламные файлы пользователь ещё не загрузил; профили сверяйте с актуальным заданием рекламодателя.
